Getting started

How it works

1

Download the app

Grab the latest Electron build for macOS, Windows, or Linux from the releases page.

2

Add your API keys

Store your provider keys locally in the app settings. We never see or collect them.

3

Pick an engine and chat

Create a project, choose a model, and start the conversation. Switch engines whenever you like.

Prefer to run from source?
git clone https://github.com/shamrock-app/shamrock.git
cd agnostic-agent && npm install
npm run dev
